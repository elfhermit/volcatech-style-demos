CI-01 / Compute — Google Cloud service

CI-01 · COMPUTE · COMPUTE ENGINE

Compute Engine

Google Cloud · Virtual machines

Virtual machines you size yourself. Start from a preset shape or set the CPU and memory ratio directly, so the instance fits the workload rather than the other way round.

Contact us All compute services

Why teams choose it

What Compute Engine is good at.

Machine shapes you define

Preset machine types cover the common cases; where they do not fit, set the vCPU and memory ratio yourself. The instance matches the workload instead of rounding up to it.

Cost levers you can actually pull

Committed use discounts sit alongside Spot instances and plain on-demand, so steady workloads and interruptible ones can be priced on different terms.

Host maintenance without a window

Live migration moves a running instance off hardware that needs servicing. Google's maintenance schedule stops being an entry in your change calendar.

Key features

What you get, specifically.

01

Custom machine types

Set vCPU count and memory independently, rather than picking the nearest preset and paying for the gap.

02

GPU accelerators

NVIDIA GPUs attach to an instance for training, inference and other workloads that will not run acceptably on CPU alone.

03

Live migration

Running instances move between hosts during maintenance events without being stopped and restarted.

Where it fits

Three situations it is built for.

Lift-and-shift

Existing server-based systems move to Google Cloud without being rewritten first — the operating system and the application stay as they are.

High-performance computing

Simulation, rendering and batch analysis on machine shapes and accelerators picked for the job.

Self-managed databases

Database engines and bespoke web services that need control of the host, not a managed abstraction over it.
