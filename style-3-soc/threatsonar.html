Key capabilities

Assess first, then stay resident.

Three scanning modes

An agentless health check with memory forensics maps what is already inside. Resident mode adds full-time EDR with isolation and restore protection; offline mode covers air-gapped environments.

Signal Pattern behavioral engine

Unknown threats are caught by how they behave, not by known indicators alone — detection rules are continuously updated from TeamT5's APT research.

Four-stage anti-ransomware

Hidden decoy files trigger blocking the moment encryption touches them, and volume shadow copies are protected from tampering to keep a restore path open.

MITRE ATT&CK investigation

Events are mapped to ATT&CK techniques on a timeline, and automated summary reports turn raw telemetry into findings your team can act on. When a finding is confirmed, responders can trigger a remote scan, isolate an endpoint or a single file, and pull a one-click analysis package for deeper forensics.

Common questions

What evaluators ask.

01How does ThreatSonar compare with SentinelOne?

ThreatSonar opens with an agentless health check and is built for hunting and forensics, with detection rules drawn from TeamT5's research into Asia-Pacific intrusion groups. SentinelOne is built for continuous prevention and automatic containment on every endpoint, every day. ThreatSonar coexists with an endpoint product you already own, so it can serve as the investigation layer rather than a replacement.

02Can it be used where endpoints have no internet access?

Yes. Offline mode scans a disconnected machine and the report is uploaded afterwards, which is how air-gapped segments get covered. The agentless health check and offline mode run on Windows, Linux and macOS. Resident mode itself is supported on Windows endpoints.

03What does the agentless health check look for?

It sweeps running memory as well as disk without installing anything, hunting for the kinds of trace signature scanning tends to walk past — backdoors, web shells, fileless command activity and hacking tools. The output is a scoped picture of which machines need resident coverage and which are clean.

04How is ThreatSonar licensed?

Licensing follows the endpoints you place under protection, and a one-off compromise assessment is scoped separately from ongoing resident coverage. Those are two different commitments, so we scope them with you — contact us.

05Can we feed our own threat intelligence into it?

Yes. Hashes, IP addresses, domains and YARA rules from your existing intelligence sources can be imported directly, and analysts can write their own hunting rules alongside the built-in set. Automated threat tracking then applies those indicators across every enrolled endpoint, so a lead found on one machine becomes a sweep of the entire estate.
