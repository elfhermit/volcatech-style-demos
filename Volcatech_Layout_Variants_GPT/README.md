# Volcatech Layout Variants

Open `index.html` in a browser. This static demo contains four layout directions and five pages per direction.

- layout-1: Magazine Editorial × Zurich
- layout-2: Split Hero + Zig-zag × Nordic
- layout-3: Bento Grid × SOC
- layout-4: Fixed Sidebar × Continental

No external CDN, framework or build step is required. Placeholder facts use the required `[TODO: ...]` syntax.
