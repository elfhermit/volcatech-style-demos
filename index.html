Volcatech — Website Style Demos

四個歐洲設計風格,同一套網站骨架

每個風格包含「首頁 + SentinelOne 產品頁」兩頁 demo,內容、選單與資訊架構完全相同,只有視覺語彙不同——請以相同標準比較。 選出勝出風格後,再用 docs/Volcatech_多風格_Build_Prompts.md 的「基底 + 勝出模組」產生完整 Astro 版官網。

怎麼比:① 3 秒測試——遮住 logo 給不知情的人看首屏 3 秒,要能答出「賣雲端 + 資安產品 + 資安服務」; ② 想像歐洲企業資安主管收到這個網址的第一印象;③ 用手機(390px)再看一次;④ 想像名片與簡報套用同風格是否成立。
Demo 範圍:導覽列中僅「SentinelOne」與「Home」可點,其餘連結為示意(游標停留會顯示 Demo scope)。 字體在 demo 以系統字體近似呈現,正式版將以 @fontsource 自行代管目標字體(GDPR)。

Style 1

Zurich Grid|瑞士型錄

精準、理性、型錄感。簽名元素:型錄索引碼(C-01 / E-01)+ 可見細網格。風險最低的基準款,工程師會點頭。

Style 2

Nordic Calm|北歐留白

沉靜、大量呼吸感、顧問式信任。簽名元素:目錄式 Hero——首頁本身就是三條產品線的安靜清單,3 秒鐵則由它直接達成。

看首頁 看產品頁

Style 3

SOC Console|資安主控台(深色)

戰情室語彙:mono 狀態列、狀態圓點、琥珀訊號色。對資安買家最有說服力——「這家公司自己就在做 SOC」。

看首頁 看產品頁

Style 4

Continental Spec|歐陸規格書(DIN)

工程規範文件語彙:編號章節、規格表卡片、細紅規線、最正式的 legal footer。德語區/歐陸採購最熟悉的可信感。
